# КОД. 3 курс. Backend. День 01

## Управление компьютерным клубом с использованием базы данных

## **Общие сведения:**

Тема: Работа с EF Core, создание моделей и запросы к базе данных

## **Технические требования:**

Вам нужно создать программу для управления сетью компьютерных залов с использованием базы данных. Программа должна использовать **Entity Framework Core** для взаимодействия с базой данных. Необходимо реализовать следующие функции:

1. **Модель пользователя (Player)** с полями:  
   * Id (уникальный идентификатор, автоинкремент, тип int)  
   * Name(имя игрока, тип string)  
   * Games (Игры которые играет Player, тип List)  
   * Sessions (Сессии игры) \-  обычный лист с ID сессий  
   * Year (год рождения, тип int)  
2. **Модель абонемента (Subscription)** с полями:  
   * Id (уникальный идентификатор, автоинкремент, тип int)  
   * PlayerId (связь с пользователем, внешний ключ к модели User)   
   * StartDate (дата начала подписки, тип DateTime)  
   * EndDate (дата окончания подписки, тип DateTime)  
   * Balance (текущий баланс, тип int)  
3. **Модель Session**:   
   * Id (уникальный идентификатор, тип int)  
   * GameName (название игры, каждая игра \= новая сессия, тип string)  
   * StartTime (время начала , тип DateTime)  
   *  Duration Minutes (продолжительность, тип int)  
   * PlayerID  (ID игрока \- внешний ключ для связки с таблицей Player, тип int )   
4. Реализовать основные операции с базой данных:  
   * Добавление игрока.  
   * Оформление абонемента для игрока.  
   * Вывод всех игр, которые играет игрок  
   * Вывод среднего времени игры игрока  
   * Удаление абонемента    
5. Используйте **LINQ** для запросов к базе данных.
